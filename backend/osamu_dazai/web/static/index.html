Generators

The generation engine is built and tested: educational planner, curriculum & learning graph, student book with terminology enforcement, teacher guide, visuals (SVG diagrams & charts), assessments with balanced versions, and IELTS Reading, Listening, Writing and Speaking. Each AI step is followed by deterministic checks; drafts that fail are sent back and never used.

On this website these tools appear once the site owner adds an AI provider key in the hosting settings. Until then they can be run from the command line — see the project README.

About Osamu Dazai

Osamu Dazai is an independent educational publishing engine. It is not affiliated with any other product or organisation.

Privacy

Uploaded files are processed in memory to produce the report and corrected document, then discarded. Nothing is stored on the server.
