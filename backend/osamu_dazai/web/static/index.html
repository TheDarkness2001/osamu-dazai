Principles

Deterministic

The same document always produces the same result. Rules, not guesses.

Private

Documents are processed in memory and discarded as soon as the response is sent.

AI only where it helps

Validation and repair use no AI at all. Generated drafts always pass human review.

No permanent storage

No accounts, no file history, nothing to leak.

IELTS · Document check

IELTS Document Validator

Checks a document exactly the way a fixed-rule importer reads it. Nothing is changed and nothing is stored.

Document
Document type

What is checked

  • Section headers stand alone on their own line
  • Every question number starts its own line
  • No missing, duplicated or out-of-order numbers
  • Question ranges match their contents
  • Heading lists use literal roman numerals
  • Answer key is complete and correctly placed

Files are processed in memory and never stored.

Document integrity

Wording is never changed

Only line breaks are inserted and Word numbering is turned into text. If a fix would change a single character of the wording, the repair is rejected.
